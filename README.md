# 프로젝트명: FENO 측정API 서버

## [1] 프로젝트 개요 및 기간

  본 프로젝트는 의료 현장에서 의사가 호흡기 질환 환자에게 FENO를 측정하고 측정 데이터를 실시간으로 API 서버에 전달한 다음
이를 바탕으로 환자의 호흡기질환 여부를 판단하는 프로젝트입니다.

   의사는 FENO 측정 장비를 통해 flow_rate(호기 유속), nitric_oxide(일산화질소 농도), pressure(압력) 값을 수집하며
 수집한 데이터로 각 환자에 대한 평균 일산화질소 농도 및 평균 압력을 계산하고, 이를 토대로 환자가 호흡기 질환(ex: 천식)
 을 가지고 있을 가능성을 판단할 수 있도록 지원합니다.

   궁극적인 목표는 일산화질소 농도 및 압력 데이터를 기반으로 호흡기 질환의 유무를 예측할 수 있는 기반을 마련하는 것이며
 이를 통해 의료진의 임상적 의사결정을 보조하고자 합니다.

- **진행 기간**: 2025.02.03 ~ 2025.02.28
- **담당 역할**:
  -  RESTful API 설계 및 구현 (Spring Boot 기반)
  -  데이터베이스 모델링 및 MariaDB 연동
  -  전역에러 처리,회원가입 및 로그인, FENO 측정 로직, 환자 정보 조회 구현
  -  Docker 기반의 애플리케이션을 AWS EC2에 배포하며, GitHub Actions과 도커허브를 통한 CI/CD를 구축
 ---

## [2] 기술 스택

- 언어: Java 17
- 프레임워크: Spring Boot 3.4.2
- 빌드 도구: Gradle
- 데이터베이스: MariaDB, Spring Data JPA
- 보안: Jasypt (설정값 암호화), JBCrypt (비밀번호 해싱)
- API 문서화: SpringDoc OpenAPI (Swagger UI)
- 기타: Lombok (코드 간소화)

## [5] 후기

  이번 인턴십을 통해 한달동안 실무는 어떻게 이루어지는지 간접적으로 살펴보았다. 이번 인턴쉽을 통해 
RESTful API 설계,ERD 작성,API 명세서,공통응답 바디 구현, 전역 예외 처리, 문서화 등의 개념을 실제 프로젝트에 
처음 적용해보며, 실무 수준의 백엔드 개발 흐름을 체계적을 이해할 수 있었습니다. 

  사내 회의에 여러 차례 참석하면서 실무진 간의 커뮤니케이션 방식과 고객의 요구사항을 반영하기 위한 논의 과정을 
직접 관찰할 수 있었습니다. 이를 통해 현업에서의 협업과 커뮤니케이션의 중요성을 실감하게 되었습니다

을 본 경험이였습니다. 간호사분 들도 이해하기 쉽게 누구나 알 수 있는 용어를 사용하며 설명하는 것을 보면서 사용자 눈높이
